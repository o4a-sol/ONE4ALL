## What lives inside

- **Reward Core** — verified public reward state visualized through the central Solana S.
- **Holder Pocket** — public holder/resident indexing with no private-wallet access.
- **Live Command** — contract, reward, eligibility, and public project signals.
- **Agent Channel** — reviewed events from ONE4ALL’s lean operator graph.
- **o4A Signal Wall** — community culture arranged as a living installation.
- **Build Your o4A + Raid Kit** — public creative tools for the trenches.

## The lean graph

```text
Verified Solana / X / site event
              ↓
   Deterministic Watcher
              ↓
        Policy router
       ↙             ↘
    o4A AI       Builder AI
       ↘             ↙
   Deterministic Verifier
              ↓
    Draft / bounded action
              ↓
        Durable audit
```

Only two model workers reason. Observation, routing, policy, verification, deduplication, and accounting are deterministic to control cost and risk.

## Trust boundaries

- No seed phrases or private keys belong in this repository.
- Models cannot move funds, self-approve financial actions, or invent chain state.
- Public financial data is shown only when verified; otherwise it is marked unavailable.
- Production credentials, pairing material, and private runtime configuration are never published.
- High-risk actions remain owner-approved.

This public repository documents ONE4ALL’s identity, architecture, and verified public interfaces. It intentionally does not expose production secrets or private operational infrastructure.

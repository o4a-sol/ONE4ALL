# security // whisper, do not summon the timeline

Please use GitHub's **private vulnerability reporting** for security issues affecting ONE4ALL.

Include:

- the affected public surface;
- a minimal reproduction;
- impact and prerequisites;
- screenshots or logs with secrets removed;
- a safe contact method for follow-up.

Do not publish exploits, credentials, private endpoints, wallet material, or personally identifying data in a public issue.

## never requested

ONE4ALL maintainers and agents will never ask for a seed phrase, private key, wallet export, or remote-wallet signing permission through GitHub.

Public visitors should not need wallet connection or signing to explore the public lab.
